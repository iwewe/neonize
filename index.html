Neonize adalah library Python yang memungkinkan automasi WhatsApp untuk komunikasi darurat dan koordinasi tim dalam situasi kebencanaan Sumatera 2025 oleh beberapa Organisasi Masyarakat Sipil . Dibangun di atas Whatsmeow (Go library), menghadirkan performa tingkat enterprise dengan kemudahan Python.

🏗️ Arsitektur Sistem Kebencanaan

📱 WhatsApp Web API

Interface komunikasi dengan WhatsApp menggunakan protokol Web API resmi

🔧 Whatsmeow (Go)

Core engine berbasis Go untuk performa tinggi dan efisiensi

🐍 Neonize Python Wrapper

Layer Python yang user-friendly untuk integrasi mudah

🗄️ Database Layer

SQLite/PostgreSQL untuk menyimpan sesi dan data pesan

🎯 Event System

Event-driven architecture untuk handling real-time messages

🚨 Aplikasi Kebencanaan

Sistem manajemen bencana yang terintegrasi

🔌 Workflow Koneksi & Autentikasi

Inisialisasi Client
Aplikasi membuat instance NewClient dengan nama sesi unik dan konfigurasi database
client = NewClient("disaster_response_bot", database="./disaster.db")
Koneksi ke WhatsApp Server
Client menghubungi WhatsApp Web server dan memeriksa keberadaan sesi tersimpan
Autentikasi
Pertama kali: Menampilkan QR Code atau Pairing Code untuk di-scan/input dari WhatsApp mobile
Sesi aktif: Menggunakan kredensial tersimpan dari database
Event Registration
Mendaftarkan event handlers untuk berbagai jenis event (pesan masuk, koneksi, status, dll)
@client.event def on_connected(client, event): print("✅ Bot terhubung dan siap!")
Siap Beroperasi
Bot siap menerima dan mengirim pesan secara real-time

💬 Workflow Penanganan Pesan

1. Pesan Masuk dari WhatsApp

Server WhatsApp mengirim pesan ke client melalui WebSocket connection yang sudah terenkripsi end-to-end

2. Whatsmeow Processing

Go engine memproses raw message, melakukan dekripsi, dan parsing protobuf message

3. Event Dispatch

Neonize mendeteksi tipe event (MessageEv, ReceiptEv, dll) dan memanggil handler yang sesuai

4. Application Logic

Handler aplikasi memproses pesan sesuai logika bisnis (parsing command, validasi, dll)

5. Response Generation

Aplikasi membuat response message (text, media, lokasi, dll) menggunakan builder functions

6. Send Message

Neonize mengirim pesan melalui Whatsmeow ke WhatsApp server dengan enkripsi E2E

7. Delivery Confirmation

Menerima receipt event untuk konfirmasi pesan terkirim/terbaca

🎯 Event-Driven Architecture

Event Types yang Tersedia:

📨
MessageEv

Event saat pesan baru diterima (teks, media, dokumen)

✅
ConnectedEv

Event saat bot berhasil terhubung ke WhatsApp

📧
ReceiptEv

Event untuk status pesan (terkirim, tersampaikan, dibaca)

📞
CallOfferEv

Event saat ada panggilan masuk

💬
PresenceEv

Event untuk status online/typing pengguna

👥
GroupEv

Event untuk perubahan grup (member join/leave, dll)

Database sederhana untuk menyimpan laporan disaster_reports = [] @client.event def on_connected(client: NewClient, event: ConnectedEv): print("🚨 Sistem Manajemen Bencana AKTIF") print(f"📱 Device: {event.device.User}") # Kirim notifikasi ke admin admin_jid = build_jid("628123456789") # Nomor admin client.send_message(admin_jid, "✅ Sistem online dan siap menerima laporan") @client.event def on_message(client: NewClient, event: MessageEv): text = event.Message.conversation or event.Message.extendedTextMessage.text sender = event.Info.MessageSource.Sender chat = event.Info.MessageSource.Chat # Command: Lapor Bencana if text and text.startswith("/lapor"): handle_disaster_report(client, chat, sender, text, event) # Command: Status Bencana elif text == "/status": send_disaster_status(client, chat) # Command: Bantuan Darurat elif text == "/darurat": handle_emergency(client, chat, sender) # Command: Lokasi Shelter elif text == "/shelter": send_shelter_info(client, chat) # Handle foto/video laporan elif event.Message.imageMessage or event.Message.videoMessage: save_media_report(client, event) def handle_disaster_report(client, chat, sender, text, event): """Menangani laporan bencana dari masyarakat""" # Parse laporan: /lapor [jenis] [lokasi] [keterangan] parts = text.split(" ", 3) if len(parts) < 3: client.send_message(chat, "❌ Format salah!\n\n" "Format: /lapor [jenis] [lokasi] [keterangan]\n" "Contoh: /lapor banjir Jl.Sudirman Ketinggian 50cm") return report = { "id": len(disaster_reports) + 1, "timestamp": datetime.now().isoformat(), "reporter": sender, "type": parts[1], "location": parts[2], "description": parts[3] if len(parts) > 3 else "", "status": "pending" } disaster_reports.append(report) # Konfirmasi ke pelapor client.send_message(chat, f"✅ LAPORAN DITERIMA\n\n" f"ID: #{report['id']}\n" f"Jenis: {report['type'].upper()}\n" f"Lokasi: {report['location']}\n" f"Waktu: {datetime.now().strftime('%H:%M:%S')}\n\n" f"Tim akan segera menindaklanjuti. 🌟 Framework Neonize untuk Kebencanaan?

Jangkauan Luas
WhatsApp digunakan oleh 2+ miliar pengguna global. Hampir setiap orang memiliki WhatsApp, tidak perlu install aplikasi baru untuk menerima informasi bencana.
Real-time & Reliable
Pesan terkirim instant dengan konfirmasi delivery. Built-in retry mechanism dan connection resilience untuk jaringan tidak stabil saat bencana.
Mudah Digunakan
Interface WhatsApp yang sudah familiar. Tidak perlu training khusus untuk masyarakat, cukup kirim pesan seperti biasa.
Rich Media Support
Kirim foto kondisi lapangan, video dokumentasi, file PDF peta evakuasi, voice note instruksi, dan lokasi GPS.
Hemat Bandwidth
WhatsApp mengoptimalkan penggunaan data. Penting saat infrastruktur terbatas dan jaringan lemah pasca bencana.
Scalable & Performant
Arsitektur Go backend memungkinkan handling ribuan pesan per detik. PostgreSQL support untuk jutaan record data.
Open Source & Free
Neonize adalah open source (Apache 2.0 License). Tidak ada biaya lisensi, cocok untuk organisasi kemanusiaan dengan budget terbatas.
